# PrepSuite production release — 2026-10-11

Later update: [the ratings repair release](2026-10-11-ratings.md) supersedes the history failure described below. Live history now works through a dynamically fetched backup with official FIDE first, a bounded deadline and source attribution. The original release evidence below is retained as history.

## Deployed scope

Live at https://prepsuite.ai: mobile profile layout, connected Preparation tab and round sheet, section-based PDF export, public-page HTML/metadata/canonicals/sitemap/social preview, and clearer messaging about linking tournament players to Chess.com/Lichess accounts and combining online/OTB games.

The frontend runs on the existing production backend image, with only the compiled FIDE history route and parser overlaid. Unrelated jobs, billing, shared-limit and database-migration work in this workspace was not deployed. Existing server configuration and secrets were preserved.

## Data integrity and remaining issue

Production rating history performs dynamic requests to FIDE, then ChessTools. There are no bundled rating-history snapshots, player-specific data fallbacks, or snapshot-generation scripts in this release. A briefly deployed snapshot fallback was removed in response to the user's instruction. Existing sample reports remain explicitly labeled historical examples.

FIDE history is still unavailable from production: official HTTPS requests timed out from Cloud Run in both US and Europe and from Cloud Build; the third-party mirror also failed. Local official requests succeeded. The endpoint returns 503 and the UI/PDF explicitly marks history unavailable and saved ratings as potentially outdated. This release therefore does not establish that every feature works. Temporary diagnostic service and traffic tags were removed.
