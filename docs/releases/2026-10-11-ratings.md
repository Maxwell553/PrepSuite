# Live ratings repair — October 11, 2026

## Behavior

FIDE history, player profiles and name searches request the official FIDE website first. History uses FIDE's own chart JSON endpoint, `/a_chart_data.phtml?event=<id>&period=0`, with POST and the headers expected by the site. If the official request fails, the service requests actual FIDE data from Lichess's FIDE database API. That API does not require the player to have a Lichess account. USCF search and profiles now use the public US Chess ratings API rather than repeatedly scraping the old MSA site.

FIDE/USCF enrichment runs concurrently under one 6.5-second deadline. History has its own 6.5-second server deadline and a 7-second client deadline. Requests are cancelled at the deadline; there are no automatic retry loops or focus/polling retries. Online account discovery and game collection have separate budgets, so this is not a seven-second guarantee for the complete report.

Only successful dynamically fetched provider responses are cached, for five minutes in memory. No bundled player records, invented history points or player-specific fallback ratings are used by these paths. Missing provider data remains missing. The UI identifies the history source and latest available period, and explicitly notes that backup coverage may lag FIDE.

The homepage search input has 10px horizontal padding and a focus indicator around the complete search field, removing the tight inner rectangle shown in the reported screenshot.

## Remaining provider limitation

Direct connections from the deployed Cloud Run runtime to `ratings.fide.com` still time out before TCP connection establishment. DNS resolves correctly. Alternate runtime generations, dedicated egress addresses and temporary compute/function probes did not resolve this. Consequently the verified production results currently use the permitted Lichess backup, despite official FIDE being first in the lookup order. This is a functional history restoration, not a claim that direct production-to-FIDE connectivity is repaired.

Backup completeness differs by player: Max's retrieved backup ended in April 2026, while the official endpoint returned October 2026; both reported 1957. Magnus's and Max Wen's backup responses included October and August 2026 respectively. The application does not fabricate missing months or imply the backup is guaranteed current.
