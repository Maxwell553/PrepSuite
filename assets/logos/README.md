# Logo Assets

Source logo files for Prepsuite.ai.

- **NewLogo.jpg** — Main logo (white text, for dark backgrounds). Deployed to `public/NewLogo.jpg`.
- **tabimage.png** — Shield icon for favicon/browser tab. Deployed to `public/tabimage.png`.
- **EmailLogo.jpg** — Alternative logo for email templates (optional; emails currently use NewLogo.jpg).

When updating logos, replace the file here and copy to `public/` so the app serves the new version.
